# Mermaid 图表（CC GUI 插件）

把聊天回答里的 ` ```mermaid ` / ` ```mmd ` 围栏代码块渲染成真正的图表（flowchart / sequence / class / state / ER / gantt …），深浅色主题自动跟随。

## 功能

- **流式安全**：只渲染「围栏已闭合」的代码块；模型输出过程中半截的 mermaid 继续按普通代码块显示，闭合那一刻才出图，不对残句反复渲染。
- **失败降级**：语法错误、资源加载失败一律退回显示源码 + 一行提示，不抛异常、不影响聊天渲染。
- **不覆盖宿主代码块**：只接管 mermaid 围栏，其余代码块的卡片、复制按钮、文件链接行为完全不变。
- **主题跟随**：宿主切换深/浅色时自动重渲染（节点填充、描边、文字颜色都跟着换）。
- **大小可调**：显示大小三档（小 ×0.7 / 中 ×0.85 / 原尺寸 ×1，等比几何缩放，改完即时生效）；布局密度两档（标准 = mermaid 默认 16px 字号与间距，紧凑 = 13px + 紧凑间距，长流程图可省约 35% 高度）。
- **不联网**：mermaid 11.17.2（MIT）作为随包资源，首次出现图表时才加载，之后复用。

## 安装

- 插件市场搜索「Mermaid 图表」安装；
- 或侧边栏「插件」→「从本地目录安装」→ 选择本仓库目录（含 `manifest.json` 那一层）。

## 设置

设置 → 插件 → Mermaid 图表：

| 分组 | 档位 | 说明 |
| --- | --- | --- |
| 显示大小 | 小 ×0.7 / 中 ×0.85 / 原尺寸 ×1 | 对已渲染的 SVG 做等比几何缩放（字号、线宽、箭头一起缩），即时生效，不重新出图 |
| 布局密度 | 标准 / 紧凑 | 决定 mermaid 出图时的字号与节点间距（16px + 默认间距 / 13px + 紧凑间距），切换会重新出图 |

选择记录在本机插件存储里（`chartScale` / `chartDensity`）。

## 权限

| 权限 | 用途 |
| --- | --- |
| `ui:markdown` | 注册 Markdown 渲染扩展（把 mermaid 围栏换成图表） |
| `ui:settings-section` | 提供「显示大小 / 布局密度」设置页 |
| `i18n` | 注册中英文文案（zh-CN / en），界面跟随宿主语言 |
| `assets:bundle` | 从插件自身包内读取随包资源 `mermaid.min.js`（本地文件，不联网） |
| `storage` | 记住显示偏好 |

不声明网络、执行外部命令等任何授权。

## 实现要点

- 经 `ctx.ui.registerMarkdownRenderer` 注入一个 rehype 插件 + `div` 组件：rehype 插件把 `<pre><code class="language-mermaid">` 就地改写成带标记 class 的 `<div>`（文本原地保留，不额外复制源码，避免宿主 reveal 的字符偏移错位），`div` 组件再把 mermaid 渲染出的 SVG 挂上去。宿主自带的 `pre`/`code` 组件因为 `components` 合并顺序是「宿主在前、插件在后」而不受影响，只占用宿主未覆盖的 `div`。
- 是否「已闭合」用节点 `position` + markdown 原文切片判定（与宿主的代码高亮缓存同款逻辑）。
- `securityLevel: "strict"`，SVG 经 `DOMParser` + `importNode` 挂载，不走 `innerHTML`。
- 渲染走串行队列：mermaid 的 `initialize` 是全局配置，避免多图并发时串主题。
- 渲染 id 带每次激活的随机标签，失败兜底清理只删自己挂载点之外的残留节点。
- 已知限制：只识别 `mermaid` / `mmd` 两种围栏语言；其它围栏不接管。
